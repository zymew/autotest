# 第一阶段实操总清单

这份文档把第一阶段沙盒验证需要做的事情，整理成统一格式：

- 在哪台机器
- 用什么工具
- 通过的方法/步骤
- 实现什么结果

建议执行顺序：

1. 先搭控制机网络与服务
2. 再制作 WinPE
3. 再让 1 台 DUT 跑通
4. 最后再上双 DUT 和 BurnInTest 长时老化

## 3. 控制机固定 IP

`在哪台机器`

- Ubuntu 控制机

`用什么工具`

- 终端
- `ip addr`
- `nano`
- `netplan`

`通过的方法/步骤`

1. 执行：

```bash
ip addr
```

2. 找到连接交换机的网口名
3. 查看 netplan 配置文件：

```bash
ls /etc/netplan
```

4. 编辑配置，示例：

```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    enp1s0:
      dhcp4: no
      addresses:
        - 192.168.10.1/24
```

5. 应用：

```bash
sudo netplan apply
```

`实现什么结果`

- 控制机固定为 `192.168.10.1`

## 5. 配置 dnsmasq

`在哪台机器`

- Ubuntu 控制机

`用什么工具`

- `nano`
- `systemctl`

`通过的方法/步骤`

1. 编辑 `/etc/dnsmasq.conf`
2. 写入：

```ini
interface=enp1s0
bind-interfaces

dhcp-range=192.168.20.100,192.168.20.200,10m
dhcp-option=3
dhcp-option=6

dhcp-boot=ipxe.efi
enable-tftp
tftp-root=/srv/tftp
```

3. 重启：

```bash
sudo systemctl restart dnsmasq
sudo systemctl status dnsmasq
```

`实现什么结果`

- DUT 开机后能拿到 IP 并获取 `ipxe.efi`

---

## 6. 配置 nginx

`在哪台机器`

- Ubuntu 控制机

`用什么工具`

- `nano`
- `nginx`

`通过的方法/步骤`

1. 创建站点配置
2. 写入：

```nginx
server {
    listen 192.168.10.1:80;
    root /srv/http;

    add_header Accept-Ranges bytes;

    location /boot.wim {
        sendfile on;
        tcp_nopush on;
    }
}
```

3. 启用站点并重启 nginx

`实现什么结果`

- 控制机能提供 `wimboot`、`boot.wim` 和规格库文件
